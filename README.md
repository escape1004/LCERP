# Local ERP

개인 파일과 기록을 로컬 PC에서 관리하는 Electron 기반 데스크톱 앱입니다. 폴더만으로 정리하기 어려운 자료를 카테고리, 사용자 정의 필드, 관계형 연결로 구조화하고 이미지, 동영상, 압축파일을 바로 확인할 수 있습니다.

## 주요 기능

- 카테고리와 하위 카테고리 구성
- 텍스트, 숫자, 날짜, 체크박스, 선택 목록, 태그, 파일, 관계형 필드 지원
- 테이블 및 갤러리 보기, 필드별 검색과 필터, 정렬과 페이지 이동
- 이미지, 동영상, ZIP/7Z 압축파일 뷰어와 영상 북마크
- CSV 및 Excel 가져오기/내보내기
- 프로필별 데이터 분리와 로컬 데이터베이스 백업/복원
- 카테고리 대시보드, 파일 누락/관계 오류 경고, 레코드 조회수 랭킹
- 번역 API를 이용한 자동 번역과 직접 입력 번역 필드
- 앱 비밀번호, 로그인 실패 잠금, 백그라운드 음소거 등 환경 설정

## 데이터와 개인정보

- 레코드와 설정은 사용자의 PC에 저장됩니다.
- 첨부파일은 기본적으로 원본 경로를 참조하며, 파일을 앱으로 복사하지 않습니다.
- 번역 기능을 사용할 때만 입력한 텍스트가 설정한 번역 API로 전송됩니다.
- 중요한 데이터는 환경 설정의 백업 기능과 별도 저장소를 함께 사용해 보호하세요.

## 시작하기

1. 앱을 실행하고 사용할 프로필을 선택하거나 만듭니다.
2. 카테고리를 만들고 필요한 필드를 정의합니다.
3. 레코드를 추가하고 파일 또는 관계형 데이터를 연결합니다.
4. 목록에서 검색, 필터, 정렬로 자료를 찾습니다.
5. 대시보드에서 카테고리 현황, 경고, 조회수 랭킹을 확인합니다.

## 개발 환경

### 요구 사항

- Node.js 20 이상 권장
- npm
- Windows, macOS 또는 Linux

### 설치 및 실행

```bash
npm install
npm run electron:dev
```

### 검증 및 패키징

```bash
# 타입 검사 및 프로덕션 번들 생성
npm run build

# 정적 검사
npm run lint

# 설치 파일 생성
npm run electron:build
```

## 주요 단축키

| 단축키 | 동작 |
| --- | --- |
| `Ctrl + F` | 검색으로 이동 |
| `Ctrl + N` | 레코드 추가 |
| `F2` | 선택한 레코드 수정 |
| `F5` | 현재 목록 새로고침 |
| `,` / `.` | 동영상 이전 / 다음 프레임 이동 |
| 방향키 | 목록 또는 뷰어에서 항목 이동 |

## 보안 설정

환경 설정의 보안 탭에서 앱 비밀번호를 설정할 수 있습니다. 비밀번호가 설정된 경우 앱 시작 시 잠금 해제 화면이 표시됩니다. 연속 실패 횟수와 잠금 시간은 기본값 5회, 1분이며 변경할 수 있습니다.

## 문제 해결

### 첨부파일 미리보기가 보이지 않을 때

- 원본 파일이 이동되거나 삭제되지 않았는지 확인합니다.
- 레코드에 저장된 파일 경로가 올바른지 확인합니다.
- 대시보드의 파일 누락 경고 또는 데이터베이스 뷰어의 정리 기능을 사용합니다.

### 번역 기능을 사용할 수 없을 때

- 환경 설정에서 번역 API 키가 등록되어 있는지 확인합니다.
- API 크레딧 또는 할당량이 충분한지 확인합니다.
- API 키가 없어도 번역 필드는 직접 입력할 수 있습니다.
