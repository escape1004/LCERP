# Local ERP System

## 프로젝트 개요

- **Electron + React + TypeScript** 기반의 로컬 ERP 시스템
- 대용량 파일(동영상, 이미지, 압축 등) 관리: 파일을 복사하지 않고 **원본 경로만 DB에 저장**
- 썸네일/미리보기/경로 복사/원본 열기 등 부가 기능 제공
- **ffmpeg-static**을 require로 동적으로 경로 처리하여 어떤 OS/경로/배포 환경에서도 동작
- 썸네일 해상도: **400x400** (이미지, 동영상, 압축 모두)
- 썸네일 생성 정책: **리스트 접근 시 생성 X, 상세/등록/수정/재생성에서만 생성**
- 리스트/상세/등록/수정/재생성 등 모든 썸네일/파일/태그 관련 정책 명확 적용
- **고정 헤더(Sticky thead) + 정렬/검색/페이징/태그 스타일 통일**
- DB/카테고리/필드/레코드 관리, 미노출(숨김) 필드 처리, 브레드크럼 UI 등 실무적 개선
- **경로 하드코딩 없음**: 어떤 디바이스/경로/OS에서도 동작
- 빌드/배포/모듈 호환: CommonJS/ESM, tsconfig.build.json 별도 관리
- **실시간 커밋/푸시**로 코드 변경 이력 관리
- UI/UX: 리스트/상세 태그 pill 스타일, 안내 메시지, 기본값 보장, 브레드크럼 등 반복 개선

## 주요 기능

- 파일/동영상/이미지/압축 등 원본 경로 기반 관리
- 썸네일/미리보기/경로 복사/원본 열기/재생성 등 부가 기능
- 카테고리/필드/레코드/DB 관리, 숨김 필드, 브레드크럼, 태그 스타일 통일
- 리스트/상세/등록/수정/재생성 등 썸네일 정책 일관 적용
- 고정 헤더 + 정렬/검색/페이징/태그 pill 스타일
- 빌드/배포/모듈 호환성, 경로 하드코딩 없음

## 개발/운영 정책

- **ffmpeg-static** 동적 require로 경로 문제 완전 해결
- 썸네일 해상도 400x400, 리스트 접근 시 썸네일 미생성 정책
- UI/UX: 태그 pill 스타일, 안내 메시지, 브레드크럼 등 실무적 개선
- 커밋/푸시로 모든 변경 이력 관리
- npm 의존성, 타입, linter 등 실시간 점검 및 해결

## 빌드/실행

1. `npm install`
2. `npm run build` (또는 `npm run dev`)
3. Electron 앱 실행

## 기타

- 모든 주요 정책/구조/코드는 실무적이고 세밀하게 관리됨
- 문의/이슈는 커밋 이력 또는 이슈 트래커 참고

## 주요 기능

- **카테고리 관리**: 비즈니스 데이터를 카테고리별로 구분하여 관리
- **데이터베이스 관리**:

  - 직관적인 네비게이션
  - 실시간 피드백 시스템

## 시작하기

### 개발 환경 설정

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run electron:dev

# 프로덕션 빌드
npm run electron:build
```

- Windows: NSIS 인스톨러
- macOS: DMG 패키지
