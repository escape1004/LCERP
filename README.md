# Local ERP System

## 이 프로그램은 무엇인가요?

- 회사나 개인이 컴퓨터에서 파일(동영상, 사진, 압축파일 등)을 쉽고 체계적으로 관리할 수 있게 도와주는 프로그램입니다.
- 파일을 복사하지 않고, 원본 위치만 기록해서 공간을 절약합니다.
- 파일을 한눈에 볼 수 있는 미리보기(썸네일) 기능이 있습니다.
- 파일을 분류(카테고리)별로 정리할 수 있습니다.
- 필요한 파일을 빠르게 검색하고, 정렬할 수 있습니다.
- 파일의 경로를 복사하거나, 원본 파일을 바로 열 수 있습니다.
- 데이터는 안전하게 저장되고, 자동으로 백업할 수 있습니다.

---

## 주요 기능

- **파일 관리**: 동영상, 사진, 압축파일 등 다양한 파일을 한 곳에서 관리할 수 있습니다.
- **미리보기**: 파일의 작은 그림(썸네일)으로 내용을 미리 볼 수 있습니다.
- **카테고리 분류**: 파일을 폴더처럼 카테고리별로 나눠서 정리할 수 있습니다.
- **검색 및 정렬**: 원하는 파일을 이름, 날짜, 태그 등으로 쉽게 찾을 수 있습니다.
- **원본 열기/경로 복사**: 파일을 바로 열거나, 위치를 복사할 수 있습니다.
- **자동 백업**: 중요한 데이터가 자동으로 백업되어 안전하게 보관됩니다.
- **쉬운 사용법**: 마우스 클릭만으로 대부분의 기능을 사용할 수 있습니다.

---

## 어떻게 사용하나요?

1. 프로그램을 설치하고 실행합니다.
2. 관리하고 싶은 파일을 등록합니다.
3. 카테고리(폴더)를 만들어 파일을 분류합니다.
4. 파일을 클릭하면 미리보기가 보이고, 필요하면 바로 열 수 있습니다.
5. 검색창에 키워드를 입력해 원하는 파일을 빠르게 찾을 수 있습니다.

---

## 이런 분께 추천합니다

- 많은 파일을 한 번에 관리하고 싶은 분
- 파일을 분류하고, 빠르게 찾고 싶은 분
- 데이터 백업이 중요한 분
- 복잡한 프로그램이 아닌, 직관적이고 쉬운 프로그램을 원하는 분
