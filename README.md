# Local ERP

Local ERP는 컴퓨터에 보관한 파일과 관련 정보를 한곳에서 정리하고 찾아볼 수 있는 개인용 자료 관리 프로그램입니다.

폴더만으로 구분하기 어려운 이미지, 동영상, 문서, 압축파일 등의 정보를 원하는 항목으로 기록하고, 검색하거나 미리 볼 수 있습니다. 데이터는 사용자의 PC에 저장됩니다.

## 다운로드 및 설치

[**Local ERP v1.1.18 Windows 설치 파일 다운로드**](https://github.com/escape1004/LCERP/releases/download/v1.1.18/Local-ERP-Setup-1.1.18.exe)

다운로드한 `Local-ERP-Setup-1.1.18.exe` 파일을 실행하고 안내에 따라 설치하면 됩니다. 이전 버전이 설치되어 있다면 기존 데이터와 설정을 유지한 상태로 업데이트됩니다.

다른 버전과 전체 배포 파일은 [GitHub Releases](https://github.com/escape1004/LCERP/releases)에서 확인할 수 있습니다.

## 이런 자료를 관리할 때 유용합니다

- 이미지와 동영상처럼 파일 수가 많은 개인 자료
- 제목, 날짜, 태그, 평점 등 파일과 함께 기록할 정보
- 서로 연관된 작품, 인물, 프로젝트 또는 문서
- 용도에 따라 완전히 분리해서 관리하고 싶은 자료 모음

## 주요 기능

### 원하는 방식으로 자료 분류

- 프로필을 만들어 용도별 데이터를 분리할 수 있습니다.
- 상위 카테고리와 하위 카테고리로 자료 구조를 구성할 수 있습니다.
- 카테고리마다 필요한 입력 항목을 직접 만들 수 있습니다.
- 텍스트, 긴 글, 숫자, 날짜, 체크박스, 선택 목록, 태그, 파일, 관계형 항목 등을 지원합니다.
- 관계형 항목으로 다른 카테고리의 레코드를 서로 연결할 수 있습니다.

### 빠른 검색과 편리한 목록

- 테이블 보기와 썸네일 중심의 갤러리 보기를 제공합니다.
- 검색, 다중 검색, 필터, 정렬을 이용해 원하는 자료를 찾을 수 있습니다.
- 표시할 항목과 페이지당 개수를 상황에 맞게 조정할 수 있습니다.
- `Ctrl + R`을 누르면 현재 카테고리에서 임의의 레코드 하나를 바로 열 수 있습니다.
- CSV 또는 Excel 파일을 이용해 여러 레코드를 한 번에 가져오거나 내보낼 수 있습니다.

### 앱 안에서 파일 확인

- 이미지와 동영상을 별도 프로그램 없이 바로 볼 수 있습니다.
- 동영상 재생 위치를 북마크하고 원하는 장면으로 다시 이동할 수 있습니다.
- 압축파일 내부의 이미지, 동영상, 텍스트 파일을 차례로 넘겨볼 수 있습니다.
- 필요한 이미지나 영상 장면을 커스텀 썸네일로 지정할 수 있습니다.

### 한눈에 보는 대시보드

- 카테고리별 레코드 수와 파일 종류를 확인할 수 있습니다.
- 최근 추가한 자료와 자주 열어본 레코드를 볼 수 있습니다.
- 원본 파일 누락이나 잘못된 관계 연결을 경고로 확인할 수 있습니다.

### 선택해서 사용하는 자동 번역

- 번역이 필요한 텍스트 항목만 자동 번역 대상으로 설정할 수 있습니다.
- 한국어, 영어, 일본어, 중국어를 대상 언어로 선택할 수 있습니다.
- 번역 품질과 비용에 맞춰 OpenAI 모델을 선택할 수 있습니다.
- 자동 번역 결과를 직접 수정하거나 번역문을 수동으로 입력할 수도 있습니다.
- 자동 번역은 사용자가 버튼을 눌렀을 때만 실행됩니다.

### 데이터 보호와 정리

- 데이터베이스를 원하는 폴더에 즉시 백업할 수 있습니다.
- 자동 백업을 켜거나 끄고 실행 간격을 설정할 수 있습니다.
- 레코드와 연결되지 않은 썸네일 파일을 안전하게 찾아 정리할 수 있습니다.
- 앱 비밀번호와 로그인 실패 잠금 기능으로 다른 사용자의 접근을 제한할 수 있습니다.

### 보기 환경 설정

- UI 확대 배율과 썸네일 크기 및 맞춤 방식을 조절할 수 있습니다.
- 갤러리 기본 확대 배율과 동영상 탐색 간격을 설정할 수 있습니다.
- 창 위치 기억, 동영상 자동 재생, 백그라운드 음소거 여부를 선택할 수 있습니다.

## 시작하기

1. 배포된 설치 파일을 실행해 Local ERP를 설치합니다.
2. 앱을 실행한 뒤 새 프로필을 만듭니다.
3. 자료를 분류할 카테고리를 만들고 필요한 입력 항목을 추가합니다.
4. 카테고리에서 레코드를 추가하고 관련 파일과 정보를 입력합니다.
5. 목록과 대시보드에서 자료를 검색하고 현황을 확인합니다.

처음에는 제목과 파일 항목만으로 간단히 시작한 뒤, 필요할 때 날짜나 태그 같은 항목을 추가하는 방식을 권장합니다.

## 알아두어야 할 점

- 첨부파일은 앱 내부로 복사되지 않고 컴퓨터에 있는 원본 위치를 참조합니다.
- 원본 파일을 이동하거나 이름을 변경하면 앱에서 파일을 찾지 못할 수 있습니다.
- 데이터베이스 백업에는 원본 첨부파일이 포함되지 않습니다. 중요한 원본 파일은 별도로 백업해야 합니다.
- 자동 번역을 사용할 때만 번역할 텍스트가 OpenAI API로 전송됩니다.
- OpenAI API 키와 사용 요금은 사용자가 직접 관리해야 합니다.

## 주요 단축키

- `Ctrl + F`: 검색창으로 이동
- `Ctrl + N`: 새 레코드 추가
- `Ctrl + R`: 현재 카테고리에서 임의의 레코드 열기
- `F2`: 선택한 레코드 수정
- `F5`: 현재 목록 새로고침
- `Ctrl + ←` / `Ctrl + →`: 이전 또는 다음 페이지로 이동
- `↑` / `↓`: 목록에서 레코드 선택 이동
- `,` / `.`: 동영상에서 이전 또는 다음 프레임으로 이동

앱 화면별 전체 단축키는 환경설정의 `단축키` 탭에서 확인할 수 있습니다.

## 문제가 생겼을 때

### 첨부파일이나 미리보기가 보이지 않는 경우

- 원본 파일이 이동되거나 삭제되지 않았는지 확인합니다.
- 레코드에 저장된 파일 경로가 올바른지 확인합니다.
- 대시보드에서 파일 누락 경고를 확인합니다.

### 자동 번역을 사용할 수 없는 경우

- 환경설정의 `번역` 탭에서 OpenAI API 키가 저장되어 있는지 확인합니다.
- OpenAI API 크레딧과 사용 한도가 남아 있는지 확인합니다.
- 선택한 모델을 API 계정에서 사용할 수 있는지 확인합니다.
- API 키가 없어도 번역문은 직접 입력할 수 있습니다.

### 데이터 용량이 계속 늘어나는 경우

- 환경설정의 `데이터` 탭에서 `썸네일 파일 정리`를 실행합니다.
- 정리 기능은 레코드가 참조 중인 썸네일을 보존하고 연결되지 않은 파일만 삭제합니다.
