## 이 프로그램은 무엇인가요?

Local ERP는 개인이나 소규모 팀이 컴퓨터의 파일(동영상, 사진, 압축파일 등)을 체계적으로 관리할 수 있게 도와주는 데스크톱 애플리케이션입니다.

### 핵심 특징

- **원본 파일 보존**: 파일을 복사하지 않고 원본 위치만 기록하여 디스크 공간을 절약합니다
- **썸네일 미리보기**: 이미지, 동영상, 압축파일의 썸네일을 자동 생성하여 한눈에 확인 가능
- **유연한 분류 시스템**: 계층적 카테고리 구조로 파일을 체계적으로 정리
- **강력한 검색 및 필터링**: 필드별 검색, 파일 타입 필터, 정렬 기능 제공
- **관계형 데이터**: 카테고리 간 관계를 설정하여 연결된 데이터 관리
- **대시보드 통계**: 카테고리별 통계, 파일 타입 분포, 추가 추이 등 시각화
- **자동 백업**: 데이터베이스 자동 백업으로 데이터 안전성 보장

## 주요 기능

### 📁 파일 관리
- 다양한 파일 타입 지원 (이미지, 동영상, 압축파일, 텍스트 등)
- 파일 경로 복사 및 원본 파일 바로 열기
- 파일 크기 자동 계산 및 표시

### 🖼️ 미리보기 기능
- 이미지 썸네일 자동 생성
- 동영상 썸네일 및 재생 기능
- 압축파일 내부 파일 탐색 및 미리보기
- 이미지 회전 기능

### 📂 카테고리 시스템
- 계층적 카테고리 구조 (부모-자식 관계)
- 드래그 앤 드롭으로 카테고리 순서 변경
- 카테고리별 필드 정의 (텍스트, 숫자, 날짜, 체크박스, 파일, 관계 등)
- 카테고리별 레코드 관리

### 🔍 검색 및 정렬
- 필드별 검색 (전체, 특정 필드)
- 파일 타입별 필터링
- 필드별 정렬 (오름차순/내림차순)
- 썸네일 유무별 정렬

### 📊 대시보드
- 전체 통계 카드 (카테고리 수, 항목 수, 파일 타입별 통계)
- 카테고리별 항목 수 차트
- 파일 타입 분포 파이 차트
- 날짜별 항목 추가 추이 (일/월/년 단위)
- 카테고리별 상세 통계 및 최근 추가된 항목

### 🔗 관계형 데이터
- 카테고리 간 관계 설정
- 단일/다중 선택 관계
- 참조 횟수 표시

### 💾 데이터베이스 관리
- SQLite 기반 로컬 데이터베이스
- 데이터베이스 뷰어 (테이블 조회 및 데이터 확인)
- 자동 백업 설정
- 썸네일 동기화 점검 및 정리

### 📤 데이터 내보내기
- CSV 내보내기
- Excel 내보내기

### ⏱️ 동영상 북마크
- 동영상 재생 시 특정 시간에 북마크 추가
- 북마크 목록 관리 및 빠른 이동

## 기술 스택

### 프론트엔드
- **React 18** - UI 라이브러리
- **TypeScript** - 타입 안정성
- **Vite** - 빌드 도구
- **Tailwind CSS** - 스타일링

- **Framer Motion** - 애니메이션
- **Recharts** - 차트 라이브러리
- **Zustand** - 상태 관리
- **React Router** - 라우팅

### 백엔드
- **Electron** - 데스크톱 애플리케이션 프레임워크
- **Better-SQLite3** - SQLite 데이터베이스
- **FFmpeg** - 동영상/이미지 처리
- **Sharp** - 이미지 처리

### 주요 라이브러리
- **PapaParse** - CSV 파싱
- **XLSX** - Excel 파일 처리
- **AdmZip** - ZIP 파일 처리
- **date-fns** - 날짜 처리

## 사용 방법

### 1. 첫 실행

1. 프로그램을 실행하면 대시보드 화면이 표시됩니다
2. 좌측 사이드바에서 카테고리를 생성하거나 관리할 수 있습니다

### 2. 카테고리 생성

1. 사이드바 하단의 "+" 버튼 클릭
2. 카테고리 이름 입력
3. 필요한 필드 추가 (텍스트, 숫자, 날짜, 파일 등)
4. 저장

### 3. 레코드 추가

1. 카테고리 선택
2. "새 항목 추가" 버튼 클릭
3. 필드 정보 입력
4. 파일 필드가 있다면 파일 선택
5. 저장

### 4. 파일 미리보기

1. 레코드 목록에서 파일이 있는 항목 클릭
2. 뷰어 모달에서 이미지/동영상 미리보기
3. 이미지 회전, 동영상 재생, 압축파일 탐색 가능

### 5. 검색 및 필터링

1. 상단 검색창에 키워드 입력
2. 검색 필드 선택 (전체 또는 특정 필드)
3. 파일 타입 필터 선택 (이미지, 동영상, 압축파일)
4. 필드 헤더 클릭하여 정렬

### 6. 대시보드 확인

- 대시보드에서 전체 통계 및 차트 확인
- 카테고리별 상세 통계 확인
- 최근 추가된 항목 클릭하여 상세 정보 확인

### 7. 데이터베이스 관리

1. 사이드바 하단의 "데이터베이스 보기" 클릭
2. 테이블 목록 확인
3. 백업 설정 및 실행
4. 썸네일 동기화 점검

### 필수 요구사항

- **Node.js**: 18.x 이상
- **npm**: 9.x 이상

### 개발 스크립트

```bash
# 개발 서버 실행 (Vite)
npm run dev

# Electron 개발 모드 실행
npm run electron:dev

# 타입 체크
npm run build:main

# 린트 검사
npm run lint

# 프리뷰 모드
npm run electron:preview
```

1. 저장소 클론
2. `npm install` 실행
3. `npm run electron:dev` 실행

```
local-erp/
├── src/
│   ├── components/          # React 컴포넌트

│   │   ├── MainContent.tsx  # 메인 콘텐츠 영역
│   │   ├── Sidebar.tsx      # 사이드바
│   │   ├── ViewerModal.tsx  # 파일 뷰어 모달
│   │   └── ...
│   ├── pages/               # 페이지 컴포넌트
│   │   ├── Dashboard.tsx    # 대시보드
│   │   ├── Index.tsx        # 카테고리 페이지
│   │   └── NotFound.tsx    # 404 페이지
│   ├── hooks/               # 커스텀 훅
│   │   ├── useERPStore.ts  # 전역 상태 관리
│   │   └── useLoadingStore.ts
│   ├── main/                # Electron 메인 프로세스
│   │   ├── ipc/             # IPC 핸들러
│   │   └── main.ts          # 메인 프로세스 진입점
│   ├── types/               # TypeScript 타입 정의
│   └── lib/                 # 유틸리티 함수
```

## 문제 해결

### 썸네일이 생성되지 않아요

- 파일 경로가 올바른지 확인
- 파일이 실제로 존재하는지 확인
- 데이터베이스 뷰어에서 "썸네일 동기화 점검" 실행

### 데이터베이스 오류가 발생해요

- 데이터베이스 백업 확인
- `save/erp.db` 파일이 손상되지 않았는지 확인
- 필요시 백업에서 복원

### 프로그램이 느려요

- 많은 레코드가 있는 경우 페이지네이션 활용
- 불필요한 썸네일 정리 (데이터베이스 뷰어에서 실행)
- 데이터베이스 최적화
