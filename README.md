# Local ERP

Local ERP는 파일과 기록을 로컬에서 정리하고 찾기 쉽게 만들어 주는 데스크톱 앱입니다.

이 앱은 단순한 폴더 정리 도구가 아니라, 직접 카테고리를 만들고 필드를 정의해서 나만의 데이터베이스처럼 쓰는 용도에 가깝습니다. 예를 들어:

- 이미지, 영상, 압축파일 자료실 정리
- 작업 레퍼런스 모음 관리
- 개인 소장 파일 아카이브 정리
- 프로젝트별 기록 관리
- 항목 간 관계가 있는 자료 관리

핵심은 두 가지입니다.

- 파일을 복사해서 앱 안에 다시 저장하지 않고, 원본 경로를 기준으로 관리할 수 있습니다.
- 내가 필요한 방식으로 카테고리와 입력 항목을 설계할 수 있습니다.

## 이 앱으로 할 수 있는 일

- 카테고리를 직접 만들고 하위 카테고리까지 구성하기
- 항목마다 텍스트, 숫자, 날짜, 체크박스, 선택 목록, 파일, 관계형 필드 넣기
- 이미지, 영상, 압축파일의 썸네일과 미리보기로 빠르게 확인하기
- 테이블 뷰와 갤러리 뷰를 오가며 목록 보기
- 필드별 검색, 다중 선택 검색, 파일 종류 필터로 원하는 항목만 찾기
- CSV, Excel로 내보내기 / 가져오기
- 대시보드에서 카테고리별 현황과 최근 추가 항목 확인하기
- 프로필별로 데이터를 분리해서 사용하기
- 로컬 데이터베이스 백업과 복원 관리하기

## 이 앱이 잘 맞는 경우

- 폴더만으로는 자료를 정리하기 답답한 경우
- 파일마다 메모, 태그, 날짜, 상태값, 관계 정보를 붙여서 관리하고 싶은 경우
- 이미지나 영상이 많은 자료를 썸네일 중심으로 보고 싶은 경우
- 인터넷 서비스에 올리지 않고 로컬 PC에서만 관리하고 싶은 경우

## 처음 시작하기

앱을 처음 열면 먼저 프로필을 고르게 됩니다.

- 프로필은 서로 완전히 분리된 작업 공간입니다.
- 프로필마다 카테고리, 레코드, 대시보드 통계가 따로 유지됩니다.
- 개인용 / 업무용 / 프로젝트별로 나눠 쓰기 좋습니다.

프로필을 선택한 뒤에는 보통 아래 순서로 시작하면 됩니다.

1. 카테고리를 만듭니다.
2. 카테고리에 필요한 필드를 추가합니다.
3. 항목을 등록합니다.
4. 검색, 필터, 정렬로 필요한 자료를 찾습니다.

## 기본 사용 흐름

### 1. 카테고리 만들기

카테고리는 자료를 묶는 기준입니다.

예시:

- 영화
- 애니메이션
- 이미지 레퍼런스
- 압축 보관함
- 프로젝트 문서

카테고리 안에는 원하는 필드를 넣을 수 있습니다.

예시:

- 제목
- 제작사
- 상태
- 감상일
- 평점
- 파일
- 관련 작품

### 2. 항목 등록하기

카테고리를 선택한 뒤 `새 항목 추가`를 눌러 레코드를 등록합니다.

파일 필드가 있는 경우:

- 원본 파일 경로를 등록할 수 있습니다.
- 이미지, 영상, 압축파일은 썸네일과 미리보기가 지원됩니다.
- 파일 자체를 다시 복사하지 않고 경로 기준으로 관리할 수도 있습니다.

### 3. 목록에서 찾기

목록에서는 다음 기능을 쓸 수 있습니다.

- 전체 검색
- 특정 필드만 검색
- 다중 선택 필드 검색
- 관계형 필드 검색
- 파일 종류별 필터
- 정렬
- 페이지 이동

파일 필드가 있는 카테고리에서는:

- 테이블 뷰
- 갤러리 뷰

두 가지 방식으로 볼 수 있습니다.

갤러리 뷰에서는 `Ctrl + 휠`로 카드 크기를 조절할 수 있습니다.

## 주요 화면

### 대시보드

대시보드에서는 전체 현황을 빠르게 파악할 수 있습니다.

- 카테고리별 항목 수
- 이미지 / 영상 / 압축파일 수
- 최근 추가 항목
- 파일 누락, 관계 오류 같은 경고 항목

자료가 많아질수록 먼저 대시보드에서 상태를 확인한 뒤 각 카테고리로 들어가는 흐름이 편합니다.

### 레코드 리스트

레코드 리스트는 앱에서 가장 자주 보는 화면입니다.

- 테이블 뷰: 필드를 한눈에 비교하기 좋습니다.
- 갤러리 뷰: 파일 썸네일 중심으로 보기 좋습니다.

레코드를 더블클릭하면 상세 보기로 들어갈 수 있고, 우클릭 메뉴로 수정 / 삭제도 가능합니다.

### 파일 뷰어

파일이 연결된 항목은 뷰어에서 바로 확인할 수 있습니다.

- 이미지 보기
- 영상 재생
- 압축파일 내부 보기
- 영상 북마크
- 썸네일 재생성 / 사용자 썸네일 지정

## 검색과 정리 방식

이 앱의 장점은 “검색 가능한 정리”입니다.

단순히 파일 이름으로 찾는 수준이 아니라:

- 상태가 완료인 항목만 보기
- 특정 태그가 붙은 항목만 보기
- 특정 관계 항목과 연결된 것만 보기
- 파일이 있는 항목만 보기
- 이미지 / 영상 / 압축파일만 따로 보기

같은 방식으로 좁혀갈 수 있습니다.

자료가 늘어날수록 카테고리 구조보다 필드 설계와 검색 방식이 더 중요해집니다.

## 가져오기 / 내보내기

카테고리별로 CSV와 Excel 입출력을 지원합니다.

쓸만한 상황:

- 기존 정리 데이터를 한 번에 가져오기
- 외부에서 가공한 목록을 다시 넣기
- 특정 카테고리만 백업용으로 따로 저장하기
- 다른 사람과 표 형태로 공유하기

가져오기 결과에서는 저장된 수, 중복으로 건너뛴 수, 관계 연결 실패 수 등을 확인할 수 있습니다.

## 백업과 데이터 보관

이 앱은 로컬 데이터베이스 기반으로 동작합니다.

- 데이터는 내 PC에 저장됩니다.
- 백업 폴더를 따로 지정할 수 있습니다.
- 백업 주기도 설정할 수 있습니다.
- 데이터베이스 뷰어에서 백업 관련 작업을 할 수 있습니다.

중요한 자료를 넣는다면 백업 폴더를 별도 드라이브나 동기화 폴더로 지정해 두는 것을 권장합니다.

## 프로필 기능

프로필은 단순한 계정 개념이 아니라 작업 공간 분리 기능입니다.

예를 들면:

- 개인 자료 / 업무 자료 분리
- 팀별 / 고객별 분리
- 테스트용 / 실사용용 분리

프로필을 나누면 카테고리와 항목이 섞이지 않아서 관리가 훨씬 편해집니다.

## 자주 쓰는 단축키

앱 안에서 자주 쓰는 기본 단축키입니다.

- `Ctrl + F`: 검색창으로 이동
- `Ctrl + N`: 새 항목 추가
- `F2`: 선택한 항목 수정
- `F5`: 현재 목록 새로고침
- `위 / 아래 방향키`: 목록 선택 이동
- `Ctrl + 휠`:
  갤러리 뷰에서 카드 크기 조절

## 이런 식으로 쓰면 편합니다

### 예시 1. 영상 자료 정리

- 카테고리: 영상
- 필드: 제목, 장르, 출처, 감상 여부, 파일, 관련 시리즈

장점:

- 썸네일로 빠르게 훑기 좋음
- 시리즈 간 관계 연결 가능
- 영상 북마크 사용 가능

### 예시 2. 이미지 레퍼런스 보관

- 카테고리: 레퍼런스
- 필드: 제목, 스타일, 색감, 출처, 파일, 태그

장점:

- 갤러리 뷰로 탐색하기 좋음
- 태그/선택 필드 검색이 편함

### 예시 3. 프로젝트 자료 관리

- 카테고리: 프로젝트
- 필드: 이름, 상태, 시작일, 마감일, 문서 파일, 관련 자료

장점:

- 단순 파일 보관이 아니라 진행 상태까지 함께 관리 가능

## 사용 시 알아두면 좋은 점

- 파일을 이동하거나 삭제하면 앱에서 연결이 끊길 수 있습니다.
- 관계형 필드는 연결된 다른 카테고리 데이터를 먼저 정리해두면 편합니다.
- 자료가 많아질수록 처음부터 필드 이름을 일관되게 정하는 것이 중요합니다.
- 갤러리 뷰는 파일 중심 카테고리에서 특히 유용하고, 테이블 뷰는 비교/정렬이 더 편합니다.

## 문제가 생겼을 때 먼저 볼 것

### 썸네일이 안 보일 때

- 원본 파일이 실제로 존재하는지 확인
- 파일 경로가 바뀌지 않았는지 확인
- 뷰어 또는 데이터베이스 도구에서 썸네일 관련 정리 기능 실행

### 검색이 기대와 다를 때

- 현재 검색 대상 필드가 `전체 필드`인지 특정 필드인지 확인
- 다중 선택 필드는 여러 값을 동시에 선택했는지 확인
- 파일 종류 필터가 켜져 있는지 확인

### 데이터가 섞여 보일 때

- 현재 프로필이 맞는지 확인

## 마지막으로

Local ERP는 “파일을 쌓아두는 앱”보다 “내 방식대로 정리해서 다시 찾는 앱”에 가깝습니다.

폴더 정리만으로 한계가 느껴질 때, 카테고리와 필드를 직접 설계해서 쓰면 훨씬 강력해집니다.
